# EdgePad

EdgePad is a macOS menu-bar app that turns the left and right edges of the trackpad into quick controls for **brightness** and **volume**, with optional haptic feedback, media-strip swipes, and a quick-mute corner gesture.

The runnable project lives in [`EdgePadMac/`](EdgePadMac). The top-level `EdgePad/` folder and `EdgePad.xcodeproj` are an older/incomplete Xcode project and are not used for building.

## Prerequisites

- macOS with **Xcode 27.2** or newer (the project targets macOS 27.0)
- Xcode Command Line Tools:

  ```sh
  xcode-select --install
  ```

- [XcodeGen](https://github.com/yonaskolb/XcodeGen) (used to regenerate the `.xcodeproj` from `project.yml`):

  ```sh
  brew install xcodegen
  ```

## Get the source

```sh
git clone <repository-url> EdgePad
cd EdgePad/EdgePadMac
```

## Generate the Xcode project

The checked-in project is generated from [`project.yml`](EdgePadMac/project.yml). Regenerate it after pulling changes or editing settings:

```sh
cd EdgePadMac
xcodegen generate
```

## Build locally

All commands below are run from `EdgePadMac/`.

### Debug build (current architecture)

```sh
xcodebuild -project EdgePad.xcodeproj -scheme EdgePad -configuration Debug build
```

### Apple Silicon (arm64)

```sh
xcodebuild -project EdgePad.xcodeproj -scheme EdgePad -configuration Debug \
  -arch arm64 ONLY_ACTIVE_ARCH=NO build
```

### Intel (x86_64)

```sh
xcodebuild -project EdgePad.xcodeproj -scheme EdgePad -configuration Debug \
  -arch x86_64 ONLY_ACTIVE_ARCH=NO build
```

> Note: Xcode 27 warns that `x86_64` is deprecated for the macOS 27.0 deployment target, but the build still succeeds.

### Universal binary (Intel + Apple Silicon)

```sh
xcodebuild -project EdgePad.xcodeproj -scheme EdgePad -configuration Release \
  ARCHS="arm64 x86_64" ONLY_ACTIVE_ARCH=NO build
```

Verify the resulting binary contains both architectures:

```sh
APP=$(find ~/Library/Developer/Xcode/DerivedData/EdgePad-*/Build/Products/Release -name EdgePad.app -type d | head -1)
lipo -info "$APP/Contents/MacOS/EdgePad"
```

### Keep build artifacts in the repository

To place build products under `./build` instead of the global DerivedData folder:

```sh
xcodebuild -project EdgePad.xcodeproj -scheme EdgePad -configuration Debug \
  -derivedDataPath ./build/DerivedData build
```

## Build with Xcode

1. Open `EdgePadMac/EdgePad.xcodeproj` in Xcode.
2. Select the **EdgePad** scheme.
3. Choose **My Mac** as the run destination.
4. Press **⌘R** to build and run.

To target a specific architecture, set **Build Settings → Architectures** (or pass `ARCHS` on the command line as shown above).

## Run and permissions

EdgePad is a menu-bar app (`LSUIElement`). On first launch macOS will prompt for:

- **Input Monitoring** – required to receive trackpad touches.
- **Accessibility / Device Control & Data Access** – required to freeze the cursor while sliding.

Grant these in **System Settings → Privacy & Security**. The in-app buttons (“Allow Input Monitoring…”, “Request Device Control & Data Access”) open the relevant panes.

## Optional: signing with a developer team

By default the project uses automatic signing and falls back to “Sign to Run Locally” for ad-hoc builds. To sign with your Apple Developer team:

```sh
xcodebuild -project EdgePad.xcodeproj -scheme EdgePad -configuration Release \
  DEVELOPMENT_TEAM=YOUR_TEAM_ID build
```

## Troubleshooting

- **“Could not start the trackpad listener”** – the private `MultitouchSupport` framework is unavailable or the app lacks Input Monitoring permission.
- **x86_64 deprecation warning** – expected on Xcode 27+ for a macOS 27.0 target; the build still produces a working Intel binary.
- **Stale project after editing `project.yml`** – re-run `xcodegen generate`.
- **Permission changes not taking effect** – quit EdgePad, revoke/re-grant the permission in System Settings, then relaunch.
